lcns: `offsetOfAt58()` DELETED -- a class was growing an API so that a test could ask about its layout

**THE HUMAN ASKED "offsetOfAt58 这是啥" AND THE ANSWER IS THAT IT SHOULD NOT EXIST.** It was a `static int32_t` member function on `EngineBase` and `EquivalentEngine` whose
whole body took a temporary object's address, cast it to `std::byte*`, subtracted, and returned an int -- **and its only caller was a test**, because `offsetof` is
ill-formed on a `protected` member from outside the class.

**THAT IS THE WRONG DIRECTION.** The class grew a public accessor so that a TEST could ask a question **the class should answer at compile time**, and **it is not C++
anyone would write after reading the module.**

## And the project already had the right form, 86 times over

    static_assert(offsetof(NestingOwner, sub) == 0x08, "RE 0xB190");            dll_layout.hpp
    static_assert(offsetof(SeedPair, second) == 0x08, "RE 0x34301: mov rdx, [rdi + 8]");   nester.hpp
    static_assert(offsetof(ScoreNode, minX) == 0x20, "minX is at +0x20");       row.hpp

**a `static_assert` beside the member, where the name is reachable and the check costs nothing at run time.** **And `offsetof` cannot be used directly here** -- `EngineBase`
has a virtual destructor and a pure virtual -- **so the replacement is two `sizeof` assertions, which need no API at all**:

    static_assert(sizeof(lcns::EngineBase) == 0x60, "the base's data plus the alignment the compiler inserts after at30");
    static_assert(sizeof(lcns::EquivalentEngine) == 0x70, "so its own at58 and at60 land at 0x60 and 0x68, where RE reads 0x58 and 0x60");

**Those two numbers pin the same arithmetic the accessors did** -- and they say it before the program runs, with nothing added to either class.

## And it is now a gate stage with a planted proof

`re/g_no_offset_accessor.py` refuses a member function whose name begins `offsetOf`, and any body that casts a member's address to a byte pointer **to compute a
difference**. **It is wired into `re/gate.ps1` as the `offset-accessor` stage**, and `re/g_prove_no_offset_accessor.py` **puts this round's own mistake back**: the check
must fail with the plant and pass without it.

check's own word now.**

**AND THE COMMENTS THAT NAMED THE ACCESSORS ARE GONE TOO**, because a deleted function described in three lines of prose is a function a reader will go looking for.
