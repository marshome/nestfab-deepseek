## And the base object is 0x20 bytes, which the port's empty declaration is not

**RE 0x754DE0, 74 bytes, three callers, is a COPY/MOVE CONSTRUCTOR**, and it is worth reading because of what it refuses to be:

    754DE0  mov qword ptr [rcx], 0        ; the destination starts nulled
    754DE7  mov r8, qword ptr [rdx]       ; the SOURCE's vptr
    754DF3  mov qword ptr [rcx], r8       ; **copied into the destination**
    754DF8  mov rax, [rdx + 8]  / 754DFC  mov [rcx + 8], rax
    754E00  mov rax, [rdx + 0x10] / 754E04 mov [rcx + 0x10], rax
    754E08  mov rax, [rdx + 0x18] / 754E0C mov [rcx + 0x18], rax

**it copies the vptr, which is what a copy constructor does and a base constructor does not** -- so this is not the constructor and cannot name the fields. **But
it bounds the object: a vptr and THREE POINTERS.** The three fields' MEANINGS are not established, **so this is recorded as a size and not as three named members** --
which is the distinction the objective asks for between what an instruction supports and what a name would merely fit.
