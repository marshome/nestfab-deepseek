# `re/SWEEP.md` —— 形状级扫掠记录（**生成物，不计入"已引用"**）

## 为什么单独放一个文件

这些条目由 `re/g_sweep.py` 自动生成，内容是每个函数的**调用面、字符串、浮点常量、字段偏移范围** ——
也就是 tier C（"仅按证据识别"）那一档：**没有任何身份**，只有形状。
把它们写进 `re/findings_engine.md` 会让 `g_coverage.py` 的"已引用"从 44% 跳到 35%（数字变好看），
而**一个函数体都没有被逆向** —— 那正是本工程反复声明不做的事（见 `REPORT.md` 10.7.1）。
所以它们搬到这里，并被排除在引用扫描之外；`g_coverage.py` 仍会把它们的数量作为 **C 档**单独报出。

## 用途

它们仍然是**工作清单**：说明"还剩哪些大函数、它们调用了什么、常量是什么"，
供真正逐条读的时候挑选目标。**不要**把这些条目当成"已逆向"。

## 更正：`0x8A82F0` **不是** base64 编码器，是带原子计数的注册/初始化例程（goal round 44）**[已证实为指令序列]**

我先前把它归到"base64 字母表族"，依据是 owner 标签 `0x8A9510「.,-+xX0123456789abcdef012345」`。
**这个归属是错的**：`0x8A82F0` 自身**一个字符串都没有**（本次读数显示字符串列表为空），
那个字母表串属于别人。它的开头 28 条指令呈现的是**另一种**典型形态：

```
8a82f0  push ×8 / sub rsp,0x28
8a8300  mov rax,[rip+...] ; add rax,0x10 ; mov [rip+...],rax     ; 写一个全局（前置 +0x10）
8a830e  mov dword ptr [rip+...],1                                 ; 置一个全局标志 = 1
8a8336  lea rcx,[rip+...] ; call 0x9449E0                         ; 初始化某对象
8a8342  lock add dword ptr [rip+...],1                            ; ★ 原子自增（取索引）
8a8355  call 0x826C60 ; lea rdx,[rip+...]
8a8361  mov [rdi + rax*8], rdx                                    ; ★ 按索引写入全局数组
```

⇒ **真实角色**：**静态初始化 + 注册**（原子计数器当**索引**，把某个地址写进全局数组槽 `[rdi+rax*8]`）。
这类代码通常是"静态局部变量/工厂注册表"的初始化，**不是算法本体**。

**教训（第七次同类）**：我把**owner 的字符串**当成了**同名函数的属性** —— 归属表是"弱归属"，而我把
弱归属当成了身份。这条已在 `SWEEP.md` 里重复记录过（弱归属 ≠ 私有 ≠ 身份），这次是它的又一次显形。
**处置**：不给 `0x8A82F0` 编名字；把"原子计数 + 索引写全局数组 ⇒ 注册/初始化"这一**形态判据**记下来，
以后遇到同类形态可直接归类，不必再逐条读。
